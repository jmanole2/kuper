# Personaje de Kuper (borrador)

Capucha-cuerpo, cara negra, ojos verdes de luz, bracitos y dos patitas. Dibujado en código (`mascota.js`) para que salga idéntico en todos los videos.

- `personaje-poses.png`: normal, saludando, mira de lado, parpadeo, con celular.
- `personaje-prueba.mp4`: prueba de 4 s (camina, mira, parpadea, saluda).
- `hoja.html` / `anim.html`: abren en el navegador y regeneran las imágenes.
