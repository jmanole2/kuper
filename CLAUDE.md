# Preferencias del dueño del repositorio

- **Sitios web: SIEMPRE en PHP.** Nada de Node.js, Next.js ni otros frameworks de JavaScript en el servidor.
  - PHP 8 puro, sin dependencias de Composer, listo para subir por **SFTP a hosting compartido (DreamHost)**.
  - Base de datos: SQLite (un archivo, sin configurar nada) o MySQL si se pide.
  - URLs limpias con `.htaccess` (Apache).
- Todo en español (código comentado, administrador y textos).
- Los sitios llevan administrador propio para editar textos e imágenes, y SEO completo.
